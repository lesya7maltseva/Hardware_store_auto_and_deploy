<h1>Проект по автоматизации переноса данных о продажах в Базу данных</h1>

На сервер поступают записи о продажах в магазинах с разных касс. 
<br>Задача: Перенести эти данные на хранение в Базу данных.

<h2>Инструкция по запуску проекта.</h2>
<br>Для запуска вам потребуется настроенный сервер, субд PostgreSQL. Работа производится от пользователя root.

<h2>Настройка сервера.</h2>
Для работы проекта на сервере должны быть установлены: python3, venv, pip, postgres Если у вас всё это установлено, пропустите этот раздел.

<br>Если сервер чистый: проверим наличие python3 
<br><code>python3 --version</code>

для проверки наличия pip воспользуйтесь командой 
<br><code>pip freeze</code>

далее установим pip командами:
<br><code>apt update</code>
<br><code>apt install python3-pip</code>

сразу установим виртуальное окружение командой 
<br><code>apt install python3 venv</code> 

после этого установим postgresql
<br><code>apt-get -y install postgresql</code>

<h2>Немного о конфигурации проекта.</h2>
<br>В файле config.ini лежат параметры проекта. 
<br>Раздел Sales_data содержит словарь Shops в нем ключом является порядковый номер магазина, а значением число касс в нем. 
<br>Reciepts - отражает количество чеков в одной выгрузке. 
<br>В разделе DATABASE параметры подключения к базе данных.
<br>Если вам необходимы другие параметры - внесите изменения в этот файл.
<h2>Деплой</h2>
На сервере перейдите в папку home (если будете делать в другой папке, нужно будет в crontab поменять название первой папки в том числе - см. в разделе Автоматизация)

Чтобы загрузить проект на сервер введите команду:
<br><code>git clone https://github.com/your_git_profile/Hardware_store_auto_and_deploy.git</code>

Затем перейдите в папку проекта Hardware_store_auto_and_deploy
<br>Для того чтобы не скачивать все библиотеки на сервер воспользуемся виртуальным окружением.
<br>Создадим папку командой:
<br><code>python3 -m venv venv</code>

Активируем виртуальное окружение:
<br><code>source venv/bin/activate</code>

Устанавливаем зависимости
<br><code>pip install -r requirements1.0.txt</code>

Для подключения к базе данных изменим пароль пользователя posgtres
<br>Сменим пользователя командой:
<br><code>su postgres</code>

Подключимся к постгре командой:
<br><code>psql -U postgres</code>

Меняем пароль командой:
<br><code>ALTER USER postgres WITH PASSWORD 'my35town48'('или ваш пароль');</code>

Выходим командой:
<br><code>exit</code>

Переключимся на пользователя root командой: 
<br><code>su</code>

Потребуется повторный ввод пароля сервера

<h2>Создание Базы данных:</h2>
Настройте новое соединение Postgres и создайте базу данных
<br>Для создания базы данных используйте скрипт из папки sql в git-репозитории проекта.
<br>База данных будет содержать 2 таблицы shops с адресами магазинов и sales с с данными о продажах.
<br>Скрипт который переносит данные о продажах в БД предусматривает внесение данных о магазине. Либо вносите предварительно в БД данные, либо вносите их при первой активации скрипта.
<h2>Автоматизация</h2>
<br>Для автоматизации использован crontab 
<br>необходимые команды можно найти в папке img файл crontab в git-репозитории проекта.
<br>Откройте дополнительно подключение к серверу, либо выйдите из виртуального окружения командой 
<br><code>deactivate</code>

<br>Для того чтобы открыть crontab потребуется команда:
<br><code>EDITOR=nano crontab -e</code>
<br>в открывшемся редакторе повторите команды из скрина crontab 
<br>Скрипт генерации продаж работает в течении 1 минуты в 7 утра с понедельника по субботу
<br>Скрипт переноса в базу данных работает в течение 1 минуты в 8 утра каждый день.
<br>На этом этапе если вы поместили проект не в папку home, замените название home на свою папку. 
<br>Сохраните изменения в crontab (Ctrl+O, Enter) и закройте его(Ctrl+X)
